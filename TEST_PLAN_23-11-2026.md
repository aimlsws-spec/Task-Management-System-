## Quick Reference: Project Startup & Environment

### 1. How to Run the Backend
Open a terminal (PowerShell) and run:
```powershell
cd C:\TMS\backend
.\.venv\Scripts\python.exe -m uvicorn app.main:create_app --factory --reload --port 8000
```
- **API URL:** `http://localhost:8000`
- **Swagger API Docs:** `http://localhost:8000/docs`
- **Database:** MySQL 8 `tms` on `localhost:3306`

### 2. How to Run the Frontend
Open a second terminal (PowerShell) and run:
```powershell
cd C:\TMS\frontend
npm run dev
```
- **Frontend URL:** `http://localhost:5173`
- Vite automatically proxies `/api/*` to `http://localhost:8000`.

### 3. Default Login Credentials
- **Email:** `krishadave485@gmail.com`
- **Roles:** `Admin` + `Owner` (Full system and executive authority)
- **Database Status:** Cleaned and backfilled into default company (*SeaWind Solution*). Zero demo tasks or dummy projects.
