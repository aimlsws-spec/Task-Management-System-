### V. AI Description & Special Note Recommendation Engine (Zero-Cost Dual Cloud Engine with Company Memory)
- **Zero-Cost Pluggable Architecture ($0.00 Expense):**
  - **Primary:** Google Gemini Free API (`gemini-2.0-flash` / `gemini-1.5-flash`), providing 1,500 free requests/day with sub-second response times and native JSON schema enforcement.
  - **Secondary:** OpenRouter Free Model Pool (`meta-llama/llama-3.3-70b-instruct:free`, `google/gemini-2.0-flash-exp:free`, `qwen/qwen-2.5-72b-instruct:free`, `meta-llama/llama-3.1-8b-instruct:free`) with automatic multi-model fallback array if primary is busy.
  - **Tertiary:** Built-in smart technical heuristic fallback guaranteeing 100% uptime with 0 external dependencies.
- **Company-Scoped Entity Learning ("What is Elala?"):**
  - When an unknown brand/product name is entered (e.g., *"Elala UI changes"*), the AI challenges the user: *"We haven't seen 'Elala' before. What is it?"*.
  - When the user answers (e.g. *"B2B jewelry eCommerce mobile app and admin portal"*), the system persists it in `company_knowledge` for that `company_id`.
  - All future tasks across that company reuse the learned definition.
  - Company isolation is strictly enforced (Company 2 cannot access Company 1's entity definitions).
  - Generic IT and business terms (HRMS, TMS, auth, checkout, attendance, etc.) are recognized automatically without asking questions.
